

# 🌤 Weather App

A modern, responsive **Weather Application** built with **HTML, CSS, and JavaScript**.  
This app fetches real‑time weather data using the **OpenWeather API** and provides a clean, user‑friendly interface with cool features like **dark/light mode**, dynamic backgrounds, and error handling.

---

## ✨ Features
- 🔍 Search weather by city name  
- 🌡 Real‑time temperature, humidity, wind speed, and conditions  
- 🎨 Responsive UI/UX design (mobile → desktop)  
- 🌙 Dark/Light mode toggle  
- 🖼 Dynamic weather icons and backgrounds  
- ⚠️ Error handling for invalid city names  

---

## 🛠 Tech Stack
- **HTML5** – semantic structure  
- **CSS3** – Flexbox, Grid, responsive design  
- **JavaScript (ES6+)** – API integration, DOM manipulation  
- **OpenWeather API** – real‑time weather data
